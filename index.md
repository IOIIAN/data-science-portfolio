## Featured Project: Regression Diagnostics & Model Optimization

- **Research Question:** How can model evaluation metrics ($R^2$, MSE) and residual patterns be used to diagnose overfitting and heteroscedasticity in predictive models?
- **Current Status:** Completed

### Key Visualization & Findings
![Residual Plot](https://raw.githubusercontent.com/IOIIAN/data-science-project/main/residual_plot.png)

* **Finding:** The model demonstrated strong training performance ($R^2 = 0.91$) but lower generalization on test data ($R^2 = 0.68$). Residual analysis revealed severe heteroscedasticity, with error variance fanning out as predicted prices increased.
* **Solution Proposed:** Target log-transformation ($\log(y)$) and Ridge/Lasso regularization.
